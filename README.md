# Daniel's Portfolio Website
Responsive multi-page portfolio using HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Projects
- `contact.html` — Contact
- `gallery.html` — Gallery

## Personalise
1. Add your portrait as `images/profile.jpg`.
2. Add `images/photo1.jpg`, `images/photo2.jpg`, `videos/video1.mp4`, and `audio/audio1.mp3` for the sample gallery, or change the filenames in `gallery.html`.
3. Update your contact details and edit the sample text/skill levels.
4. Upload/commit the files to the GitHub repository connected to Render. If auto-deploy is enabled, Render should publish your changes.

## Render settings
For a static site with `index.html` in the repository root: branch `main`, Root Directory blank, Build Command blank, Publish Directory `.`.
